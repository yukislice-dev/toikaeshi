今のアプリに「決めた版」を貼り替える手順

対話ＡＩアプリ「電流とエネルギー」（コード.gs 10月16日・第11版２）。変えるのは「プロンプト.gs」の中身だけです。コード.gs・index.html・ＡＰＩキー・記録のスプレッドシート・設定シートは、そのまま使います。所要時間は５分ほどです。

やり方向いている人
Ａ　自分の手でやる（おすすめ）だれでも。コピーと貼り付けと、メニューを４回押すだけです。
Ｂ　Claude に手伝ってもらうChrome に Claude の拡張機能（Claude in Chrome）を入れられる人。貼り付けは自分で、メニューの操作と確かめを Claude に頼みます。

Ａ　自分の手でやる

0

今のプロンプト.gs を控えておく（元に戻すとき用）

Apps Script で今のプロジェクトを開き、左のファイル一覧の「プロンプト.gs」を開きます。エディタの中をクリックして Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）。Google ドキュメントやメモ帳に貼って保存しておきます。

1

決めた版のプロンプト.gs をコピーする

比較の入口ページの「３　これがいいと決めたら」で、決めた版の 「プロンプト.gs をコピー」 を押します。「コピーしました」と出れば準備完了です。

2

プロンプト.gs の中身を入れ替えて保存する

Apps Script に戻り、「プロンプト.gs」のエディタの中をクリック → Ctrl＋A（全部選ぶ）→ Ctrl＋V（貼り付け）→ Ctrl＋S（保存）。
（Mac は Ctrl のかわりに ⌘）

確かめ：上の方に「var PROMPT_VERSION = '詳細版 2026-10-17';」のように、選んだ版の名前が出ていれば正しく入っています。

3

（してもしなくてもよい）ＡＩの返事だけ先に試す

エディタ上部の関数の選択で testDialogue_miidasu を選んで「実行」。下の「実行ログ」に、先生の４つの試しの入力に対するＡＩの返事が出ます。シートには書きません。

4

公開中のアプリに反映する（URLはそのまま）

右上の 「デプロイ」→「デプロイを管理」 → 今のウェブアプリを選んで、右上の 鉛筆（編集） → 「バージョン」で 「新バージョン」 → 説明に「詳細版に貼り替え」など → 「デプロイ」。

「新しいデプロイ」ではなく、必ず「デプロイを管理」から編集してください。「新しいデプロイ」にすると、生徒に配ったURLとは別のURLができてしまいます。
5

確かめる

いつものアプリのURLを開き（開いていたら再読み込み）、画面のいちばん下に 「プロンプト：詳細版 2026-10-17」 のように、選んだ版の名前が出ていれば完了です。

元に戻したいとき

「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ 「バージョン」で、貼り替える前の番号を選んで「デプロイ」。これで公開中のアプリはすぐ元に戻ります。
そのあとコードを直すときのために、手順０で控えた元の中身を「プロンプト.gs」に貼り戻して保存しておいてください。

記録について

記録は今のスプレッドシートに続けて書かれます。「対話」シートの「プロンプト版」の列に版の名前が入るので、貼り替える前と後の記録を区別できます。

Ｂ　Claude に手伝ってもらう（Claude in Chrome）

Claude Pro では、Chrome の拡張機能「Claude in Chrome」を使って、開いているページの操作を Claude に頼めます。

おすすめの分け方：手順０〜２（コピーと貼り付け）は自分でやり、手順４〜５（デプロイの更新と確かめ）を Claude に頼みます。
長いプログラムを Claude に打ち込ませると、エディタが括弧などを自動で足して、中身が崩れることがあるためです。

準備（一度だけ）

1

パソコンの Google Chrome で「Chrome ウェブストア」を開き、「Claude」を検索して、Anthropic の Claude を「Chrome に追加」。

2

Claude Pro のアカウントでログインし、拡張機能のアイコン（パズルの形）から Claude を ピン留め します。

学校のアカウントや学校のパソコンで拡張機能が入れられない場合は、Ａの手作業でやってください。

頼み方

手順０〜２を自分で済ませたら、Apps Script のプロジェクトのタブを開いたまま、右上の Claude のアイコンを押します。横に Claude の画面が出るので、次の文をコピーして送ります（「詳細版」の所は、選んだ版の名前に変えてください）。

① 貼り替えが正しく入ったかの確認

このタブは Google Apps Script のプロジェクトです。左のファイル一覧から「プロンプト.gs」を開いて、PROMPT_VERSION の行に何と書いてあるか教えてください。中身は書き換えないでください。

② 公開中のアプリに反映（手順４）

このタブの Google Apps Script で、右上の「デプロイ」→「デプロイを管理」を開き、今あるウェブアプリのデプロイを編集して、バージョンを「新バージョン」、説明を「詳細版に貼り替え」にしてデプロイしてください。「新しいデプロイ」は作らないでください。終わったら、ウェブアプリのURLが前と同じかどうか教えてください。

③ 確かめ（手順５）

そのウェブアプリのURLを新しいタブで開いて、画面のいちばん下に「プロンプト：詳細版」と出ているか確かめてください。

元に戻すときの頼み方

このタブの Google Apps Script で、「デプロイ」→「デプロイを管理」を開き、今のウェブアプリのデプロイを編集して、バージョンを一つ前の番号に戻してデプロイしてください。「新しいデプロイ」は作らないでください。
・Claude が「このページを操作してよいか」と聞いてきたら、内容を読んでから許可してください。
・Google のログインや「アクセスを許可」の画面が出たときは、Claude に任せず自分で操作してください。
・ＡＰＩキーやパスワードは、Claude に入力させないでください（今回の貼り替えでは使いません）。

Claude in Chrome について：Get started with Claude in Chrome（Claude ヘルプセンター）

ほかの単元で使うとき（参考）

貼り替えたプロンプト.gs の先頭にある P_GRADE（学年）と P_UNIT（単元の情報）を書き換えます。それより下は、どの単元でも同じです。
ただし、入力欄・まとめの欄（コード.gs の SCENES）、演示の値や事例（設定シート）は単元ごとに作られているので、それらも合わせて直す必要があります。
